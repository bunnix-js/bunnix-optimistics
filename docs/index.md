# Bunnix Optimistics

@bunnix/optimistics provides optimistic state control while external data loads. It pairs a committed base state with an optimistic state, supports scoped transactions, and plugs into @bunnix/redux reducers and middleware.

## Fit in the Bunnix ecosystem

Use this module when you want UI to update immediately while a remote action is pending, and then commit or rollback based on the result. It is designed for Bunnix apps that already use @bunnix/redux state and middleware patterns.
